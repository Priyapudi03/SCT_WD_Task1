# Responsive Landing Page with Interactive Navigation

A modern, dark-themed landing page featuring an interactive sticky navigation menu with smooth scroll effects and animated particle background.

## ✨ Features

🔹 **Fixed Sticky Navigation** - Navigation stays at the top while scrolling  
🔹 **Scroll-based Color Change** - Nav background changes when you scroll down  
🔹 **Hover Effects** - Menu items change color smoothly on hover  
🔹 **Animated Particles** - Moving particles in the background create a dynamic effect  
🔹 **Responsive Design** - Works perfectly on mobile, tablet, and desktop  
🔹 **Modern Dark Theme** - Clean, professional dark interface with gradient accents  
🔹 **Smooth Animations** - Fluid transitions and CSS animations throughout  
🔹 **Mobile Hamburger Menu** - Hamburger menu for seamless mobile navigation  

## 🛠 Technologies Used

💻 **HTML5** - Semantic markup and structure  
🎨 **CSS3** - Styling with gradients, animations, and responsive design  
⚡ **JavaScript** - Interactive features, scroll detection, and particle animation

## 💡 Key Features Explained

### Sticky Navigation
The navigation bar remains visible at the top of the page while scrolling, allowing easy access to menu items at all times.

### Scroll Effect
When you scroll down 50px, the navigation background becomes visible with a semi-transparent backdrop blur effect for better text visibility.

### Hover Animations
Menu items change color smoothly with an animated underline appearing on hover, providing clear visual feedback.

### Particle Animation
The background features 50 animated particles that float and fade, creating a modern, dynamic atmosphere without being distracting.

### Responsive Design
The layout automatically adapts to different screen sizes using CSS media queries. On mobile devices, the menu transforms into a hamburger menu for better usability.

## 📱 Responsive Breakpoints

- **Desktop**: Full navigation menu visible
- **Tablet**: Menu items adjusted for smaller screens
- **Mobile** (≤768px): Hamburger menu toggle with collapsible navigation
